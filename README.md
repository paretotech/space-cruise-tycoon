# SS Halcyon — Space Cruise Tycoon (v0.1)

A small browser tycoon game. You run one rocket cruise ship on a 24-hour, 16-orbit loop around Earth.

- **Six decks**: Observation Lounge, Zero-G Deck, Restaurant, Gym, Cabins, Utilities — each upgradable to level 3.
- **Guests** wander between decks, spend money, and leave a review that sets your line's rating and future bookings.
- **Resources**: oxygen (tanks + recycler), food (one unit per meal), power (solar arrays that fade in Earth's shadow, plus a battery).
- **Emergencies**: hull breaches, solar flares, galley fires and more, each with a timed choice.

No build step: open `index.html`, or serve the folder with `python3 -m http.server`.
Progress is saved in the browser between cruises.
